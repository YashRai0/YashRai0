### 💰 Featured Project

<h4>Resume Optimizer</h4>

> An AI-powered resume optimization SaaS built India-first — helping job seekers pass ATS screening without paying US-style SaaS prices.

- 🎯 Full flow live: PDF upload/parsing, AI optimization (Groq), cover letter generation, and optimization history
- 💳 Razorpay payments integrated with India-first pricing (₹0 / ₹299 / ₹199 annual)
- 🔐 Security-hardened: replaced forgeable auth with verified Clerk auth, fixed missing ownership checks and unprotected routes
- 🧱 Stack: React + Tailwind, Node.js + Express, MongoDB Atlas, Clerk, Razorpay, Groq
